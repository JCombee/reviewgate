Raw machine-readable output: `dependency-graph.json`, `waves.json`. Max parallel width: 3.

## Why 3 waves, not fewer

Every story below is functionally independent — no story needs another's *behavior* to
work correctly. The wave split exists purely because of **file-level scope conflicts**
(two stories editing the same file, even in disjoint regions), which the plugin's
guardrail refuses to schedule concurrently regardless of semantic independence:

1. **`packages/web/src/App.tsx`** — touched by Story 4.1 (final-page decision branch) and
   Story 5.2 (header mount point). Disjoint regions, but the same file.
2. **`packages/core/src/index.ts`** — a shared export barrel touched by three stories:
   5.1 (adds update-check exports), 6.1 (adds pre-commit-hook exports), 7.1 (removes
   dedupe exports). A 3-way conflict cluster — no two of {5.1, 6.1, 7.1} may run together.
3. **Explicit dependency:** Story 5.2 (`update-prompt-ui`) is `Blocked-by` Story 5.1
   (`update-check-endpoint`) — the UI calls the endpoint the server story creates.

7.1 conflicts with both 5.1 and 6.1 on `packages/core/src/index.ts` (it removes exports

## Practical notes for the build

- **Owned File/Module Scope** per story (see each story's `## Owned File/Module Scope`
  section) is the source of truth for what a dev agent may touch — do not let an agent
  edit outside its story's listed files.
- `packages/core/src/index.ts` is edited by 5.1, 6.1, and 7.1 in sequence across three
  waves; each should be a small, additive (or in 7.1's case, subtractive) diff to that
  file so the merges stay trivial.
- `packages/web/src/App.tsx` is edited by 4.1 (Wave 1) and 5.2 (Wave 2) in disjoint
  regions; merging Wave 1 before starting 5.2 avoids any diff overlap.
- If a faster (single-wave) build is preferred, 6.1 and 7.1 could instead both be
  rebased onto Wave 1's merged `index.ts` state one at a time in quick succession rather
  than waiting for a full separate wave each — but that trades the clean wave boundary
  for manual sequencing discipline. The 3-wave plan above is the conflict-free default.
